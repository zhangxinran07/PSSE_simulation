## 任务：类噪声改经「新增 0 值负荷」注入（改 package/psse_dynamic.py）

张老师要求：原来 `run_psse_simulation` 里类噪声直接 `load_chng_6(bus,'1',...)` 改原负荷；改成在每个注入母线上额外加一个初值 P=Q=0 的新负荷（新 load ID），噪声全部经这个 0 值负荷注入，原 '1' 号负荷不再被动。

### 改动内容（package/psse_dynamic.py）
- 新增模块级常量：
  - `INJECT_LOAD_ID = '2 '`（注入负荷 2 字符 ID；IEEE39 每个负荷母线仅一个 '1' 号负荷，'2' 空闲，已实测）
  - `INJECT_LOAD_BUSES = [12, 7, 8, 23, 16, 18, 26, 29]`
- `init_dynamic_case(...)` 新增参数 `inject_load_buses=None`；在 `case()` 之后、`conl()` 之前，对每个注入母线 `psspy.load_data_6(bus, '2 ', [1,_i,_i,_i,1,_i,_i], [0]*8)` 新增 0 值负荷（与原有负荷走完全相同的 conl 转换/动态初始化流程）。
- `run_psse_simulation`：`load_change_buses` 提前到 `init_dynamic_case` 之前计算（仅 ambient/probing 扰动非空），注入循环 `load_chng_6` 的 ID 由 `'1 '` 改为 `INJECT_LOAD_ID`。

### 验证结论（实测通过）
- 8 个注入母线各加出 '2' 号负荷，conl 后 27 of 27 负荷转换成功，`strt_2` 初始化 ierr=0。
- 输出通道出现 `PLOD 12[LOAD12 138.00]1` 与 `PLOD 12[...]2` 两条：原 '1' 负荷恒定（max-min≈0.0006），新 '2' 负荷随噪声变化（max-min≈0.1027）→ 噪声确实进了新负荷、原负荷未动。
- 注：注入母线 7/8/16/18/23/26/29 不在 `chsb` 子系统 1 内（子系统= load_bus_monitor + [12,39]），故 .out 里没有它们的负荷通道，这是原有输出通道设计，与注入无关。

1. **PSS/E 必须用 Python 3.12**（对应 PSSPY312）。默认 `python` 是 3.13，会 import 失败。正确解释器：`C:\Users\Lenovo\AppData\Local\Programs\Python\Python312\python.exe`。

3. `load_data_6(ibus,id,intgar,realar,lodtyp)` 可**新增**负荷（id 不存在时）；`load_chng_6` **只能改已有**负荷（id 不存在 ierr=5）。INTGAR=[STATUS,AREA,ZONE,OWNER,SCALE,INTRPT,DGNFLG]，REALAR=[PL,QL,IP,IQ,YP,YQ,PG,QG]。
